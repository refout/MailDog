v0.1.1

2026-11-18 最新

补齐实时收信与统一账户视图，Engine 改为无窗口常驻——关掉界面也能继续收信。

  • IMAP IDLE 实时收信：每个账户独立监听，断线按 30 秒起、最长 10 分钟的指数退避重连。
  • Engine 无窗口化：独立托盘进程，提供打开 UI、立即同步、退出；UI 未运行时也可自行拉起。
  • 唤醒重连：系统睡眠恢复后自动重建连接并立即补一次同步，不再等下一个轮询周期。
  • 统一邮箱视图：顶部聚合所有账户的收件箱、已发送、草稿等默认文件夹，下方按账户展开二级文件夹。
  • 侧栏改用 TreeView：账户行由模板渲染，去掉横向滚动条，长邮箱地址不再挤占层级缩进。

v0.1.0

2026-11-17

首个可用版本：双进程骨架、两种登录路径、本地索引、净化渲染，以及能直接分发的 AOT 产物。

  • 双进程架构：UI 与 Engine 通过命名管道通信，4 字节长度前缀 + 源生成 JSON。
  • 两类账户：QQ 邮箱授权码登录；Outlook OAuth2 Authorization Code + PKCE（Engine 内自研回环）。
  • 本地索引：SQLite 缓存账户、文件夹、邮件头与正文，已同步内容离线可读。
  • HTML 净化：白名单标签与内联样式、CSP 约束、默认拦截远程图片，渲染失败降级纯文本。
  • 阅读体验：Fluent 三栏、暗/亮主题、搜索与筛选、7 种排序依据、按时间跳转、批量标记与附件下载。
  • 通知与托盘：气泡通知带应用图标与发件人头像，点击直达对应邮件。
  • 发布链路：两个 Native AOT 单文件；GitHub Actions 产出 x64 / arm64 便携包与 x64 安装包。
