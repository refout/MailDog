v0.3.11

2026-11-27 最新

主窗口再收一轮：搜索范围改成下拉，附件拖出不再靠按钮，左侧两栏继续收紧，账户树与邮件头像左移，同步状态不再占用底部状态栏。

  • 搜索：搜索范围从按钮切换改成下拉选择，明确列出「当前文件夹 / 全部邮箱」，不再需要从按钮文案猜当前状态。
  • 附件：删除附件行与工具栏里的「拖出 / 拖出所选」按钮，保留打开、下载；整行可拖，多选时拖任意已选行会一起拖出，点到按钮或复选框不会误触。
  • 留白：三栏外框左右 12→8，左栏内容左右 16→12，中栏标题、搜索与批量栏左右 16→12；上下边距、栏间距和阅读区保持不变。
  • 头像：账户树缩小内边距并整体左移，账户头像较 0.3.10 左移约 17px；邮件行左边距 10→2、列表项边距 6→4，列表头像左移约 10px。
  • 同步：同步中、加载中和手动立即同步不再写入底部状态栏，底栏不再随同步出现又消失、也不会把三栏顶高；同步状态只留在账户行内。
  • 验证：Release 构建 0 警告，190 项测试通过；HOME 实机确认搜索下拉、附件行和同步期间不再出现底栏。

v0.2.0

2026-11-24

这一版把「收信」这件事收得更干净：通知不再一股脑地弹，来信能按规则自己归类，发信前会提醒你别忘附件，发出去还有几秒后悔的时间；另外多了一个命令行工具，脚本和助手也能用它收发信。

  • 通知不吵了：连续来信会合成一条「收到 N 封新邮件」；可以设免打扰时段，夜里到点自动闭嘴；锁屏时只显示「收到一封新邮件」，主题和发件人不上屏。

  • 发出去还能撤回：默认留 10 秒撤销窗口（可设 0 / 5 / 10 / 30 秒），这段时间邮件停在发件箱，点「撤回」就不会真的发出去。

2026-11-24

换了新图标，通知也换了新做法：弹出来能认得出是谁发的，点一下就能翻到那封信，关掉窗口也照样跳。

  • 新图标：圆角蓝底上一个白色 M，右下角蹲着自家那只白博美。程序图标、任务栏、托盘、官网都换成了它。
  • 通知是系统的正式通知：顶部带应用图标，大图是发件人头像，边缘不再有锯齿；以前那种一会儿就没、还留不下记录的气泡通知不用了。
  • 点通知能翻到那封信：点一下就把窗口拉到前面，并定位到对应的邮件；窗口关着的话会先把窗口拉起来。
  • 通知能留底：弹出的通知会进系统通知中心，事后翻历史还能看到当时来的是什么信，也能从历史点回那封信。
  • 通知里显示什么自己定：设置里可以选通知里带不带邮件主题、带不带正文开头那几句。
  • 背景很透也能看清字：窗口调得很透的时候，邮件列表和阅读区会自动更实一点，灰色小字也会跟着变清楚，不会被桌面上的东西透过来搅乱。
  • 关于页重做：图标放大，说明改成日常说法，另外加了一份开源致谢，用到的每个库都能查到出处。

v0.1.1

2026-11-18

关掉窗口也能继续收信：新邮件立刻推到你眼前，两个邮箱的收件箱也能在同一个列表里看。

  • 新邮件立刻到：每个邮箱单独盯着，一有新信马上显示；网络断了会自己重连，不会一直卡在「收不到」。
  • 关掉窗口也能收：右下角托盘里的小图标一直待着，右键可以打开窗口、立即检查或退出；窗口没开的时候它也会自己起来收信。
  • 合盖再打开就补同步：电脑睡眠恢复后马上重连，并补收一次，不用等下一轮检查。
  • 两个邮箱一起看：收件箱、已发送、草稿这些常用文件夹放在最上面统一显示，下面再按邮箱分开，未读数一眼看到。
  • 左边栏更好用：邮箱名字很长时不会再撑出横向滚动条，也不会把下面的子文件夹挤变形。

v0.1.0

2026-11-17

第一个能用的版本：能加邮箱、能收信、能看信，下载下来就能跑。

  • 能加两种邮箱：QQ 邮箱用授权码登录；Outlook 用浏览器登录，不用填密码。
  • 离线阅读：收过的邮件会留在缓存里，没网也能翻、能搜。
  • 别人的邮件弄不乱界面：只保留安全的排版，图片默认不加载，格式坏了就退回纯文字。
  • 日常看信够了：三栏界面、深浅主题、搜索筛选、多种排序、按时间跳转、批量标记、下载附件。
  • 新邮件会提醒：桌面弹提醒，点一下直接跳到那封信。
  • 下载就能跑：程序自带运行环境，不用先装 .NET，也不用另装数据库；提供 64 位安装包，以及 64 位 / Arm 便携包。

v0.3.0 · Linux 桌面版

2026-11-25

Linux x64 从“能跑”补到“能日常用”，Windows 也接进系统入口。

  • Linux 正文与桌面：WebKitGTK 渲染 HTML，缺库自动退回纯文本；托盘图标、maildog:// 协议与二次启动交回、锁屏通知隐藏、更新识别 tar.gz。
  • 系统级入口：接管 mailto:、.eml 打开方式、默认邮件程序候选、资源管理器「发送到」、拖入 .eml 直接打开、最近邮件。
  • 诊断包：日志、版本、配置概览打成 zip，邮箱地址与正文全部脱敏，关于页一键导出；UI 崩溃留痕。
  • 账号健康面板：每个邮箱上次同步时间、IDLE 是否在连、最近一次错误与重试时间。
  • 命令行：解析层迁移到 System.CommandLine，命令、输出与退出码不变；CLI 不再随安装包展开，改为按需下载 CLI + Skill 压缩包（v0.3.1 起入口移到设置 → 工具，并直接保存到安装目录）。
