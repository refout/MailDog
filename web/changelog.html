当前版本 v0.1.1

更新日志

每个版本改了什么，这里都用日常说法写出来。每个版本都有 64 位与 Arm 的便携包，64 位另有安装包。

v0.1.1

2026-11-18 最新

关掉窗口也能继续收信：新邮件立刻推到你眼前，两个邮箱的收件箱也能在同一个列表里看。

  • 新邮件立刻到：每个邮箱单独盯着，一有新信马上显示；网络断了会自己重连，不会一直卡在「收不到」。
  • 关掉窗口也能收：右下角托盘里的小图标一直待着，右键可以打开窗口、立即检查或退出；窗口没开的时候它也会自己起来收信。
  • 合盖再打开就补同步：电脑睡眠恢复后马上重连，并补收一次，不用等下一轮检查。
  • 两个邮箱一起看：收件箱、已发送、草稿这些常用文件夹放在最上面统一显示，下面再按邮箱分开，未读数一眼看到。
  • 左边栏更好用：邮箱名字很长时不会再撑出横向滚动条，也不会把下面的子文件夹挤变形。

v0.1.0

2026-11-17

第一个能用的版本：能加邮箱、能收信、能看信，下载下来就能跑。

  • 能加两种邮箱：QQ 邮箱用授权码登录；Outlook 用浏览器登录，不用填密码。
  • 邮件存在本机：收过的邮件都存到电脑上，没网也能翻、能搜。
  • 别人的邮件弄不乱界面：只保留安全的排版，图片默认不加载，格式坏了就退回纯文字。
  • 日常看信够了：三栏界面、深浅主题、搜索筛选、多种排序、按时间跳转、批量标记、下载附件。
  • 新邮件会提醒：桌面弹提醒，点一下直接跳到那封信。
  • 下载就能跑：程序自带运行环境，不用先装 .NET，也不用另装数据库；提供 64 位安装包，以及 64 位 / Arm 便携包。
