功能

日常收信要用的，都在这儿

不追求功能清单有多长，只把每天收发邮件真正会用到的那几件事做顺。

所有邮箱，一个窗口

收件箱、已发送、草稿、存档都聚在同一个窗口里，下面再按 QQ 邮箱、Outlook 分开列。哪个邮箱有几封没读，名字旁边直接标着。

多账户未读数可见

新邮件马上到

不用手点刷新，也不用等它隔一阵去查：邮件一到服务器就推到你眼前。网络断了会自己重连，笔记本合上再打开会马上补一次。

即时到达断线自恢复

没网也能翻旧邮件

看过的信都存在你自己电脑上。断网、邮箱服务器抽风、出差路上没信号，照样能翻、能搜，翻页也不用转圈等。

离线可读存在本机

陌生邮件的样式动不了你的窗口

邮件自带的排版只留下安全的那部分，图片和附件不会自动下载。万一某封信格式坏了，就退回纯文字显示，不会把阅读区弄乱。

安全过滤图片需手动加载

关掉窗口也继续收信

窗口关了，右下角托盘里的小图标还在看着邮箱：新邮件弹提醒，点一下就直接跳到那一封。想彻底停掉，右键退出即可。

1

装好就用，没有前置条件

下载、安装（或解压），双击打开。不用先装运行库，也不用注册 MailDog 账号，登录你自己的邮箱就行。

2

窗口说关就关，不在后台堆着

关掉窗口，界面的那部分进程就退干净了，不会在后台挂一堆东西占内存；留下的只有你要的那个收信程序。

3

网络断了会自己接回来

断线后隔一会儿自动重试，越等越久但不会放弃；合上盖子再打开会立刻补一次，不用等下一轮。

4

东西都在你看得见的地方

托盘小图标固定在右下角，右键就能打开窗口、立即检查或退出；邮件和日志都在你自己的用户目录（%LOCALAPPDATA%\MailDog\）。

上手三步

三步开始看邮件

不用装运行库，也不用注册任何账号。

1

下载并安装

安装包装完会有开始菜单图标和卸载入口；不想装进系统就用便携版，解压后双击 MailDog.UI.exe，两个文件要放在同一个文件夹里。

2

登录你的邮箱

QQ 邮箱：先在网页版设置里开启 IMAP 服务，拿一串授权码填进来，不是你的 QQ 密码。Outlook：点「用浏览器登录」，在微软的页面里同意一下就行。

3

开始看邮件

登录后会自动把最近的邮件收下来，之后一直挂着等新邮件。窗口随时可以关，收信不受影响。

安装包还没买签名证书，第一次运行时 Windows 可能提示「已保护你的电脑」，点「更多信息」再点「仍要运行」就行。Windows 10 还需要补一个微软的 WebView2 组件，Windows 11 自带。
程序信息

它是什么，需要什么

支持的电脑Windows 10（1809 及以上）和 Windows 11；常见 64 位电脑，Arm 版 Windows 用 arm64 便携包
怎么装安装包，或解压即用的便携版；两种都不需要另外安装运行库
占多少空间程序约 60 MB；看过的邮件也存在本机，具体占多少看你收了多少信
支持的邮箱QQ 邮箱、Outlook（含 Microsoft 365）；其他邮箱暂时还不能加，之后会补
现在能做什么只能看：收信、搜索、标记、下载附件。写信、回复、转发在下一个版本
账号与安全登录信息只存在本机；Outlook 走微软官方登录页，MailDog 拿不到你的密码
邮件存在哪你自己的电脑上：%LOCALAPPDATA%\MailDog\。没有云端服务，也不往别处传
想看技术细节GitHub 仓库的 docs 目录里有方案与设计记录
常见问题

下载前值得看一眼

下面这几条是问得最多的。

还要另外装什么吗？

不用。程序把需要的东西都打包在里面了，不装 .NET，也不装数据库。只有 Windows 10 需要补一个微软的 WebView2 组件，Windows 11 已经自带。

支持哪些邮箱？

现在能加 QQ 邮箱和 Outlook（包括 Microsoft 365 的个人与工作账户）。其他邮箱还没在界面上开放，之后会补上。

为什么只能看、不能写信？

这一版先把「收信」这条线做扎实：收到、存好、显示清楚、及时提醒。写信、回复、转发在下一个版本，所以界面上不会有那种点了没反应的按钮。

我的邮件会被传到别的地方吗？

不会。账号信息、文件夹和看过的邮件都只存在这台电脑的 %LOCALAPPDATA%\MailDog\ 里。MailDog 没有自己的服务器，也没有云端同步。

窗口关了，还能收到邮件吗？

能。右下角托盘里的小图标还在跑，新邮件照样弹提醒；想彻底停掉，右键托盘图标选「退出」就好。

提示「Windows 已保护你的电脑」怎么办？

因为安装包没买代码签名证书。点「更多信息」再点「仍要运行」就行。如果你是从源码自己构建的，不会看到这个提示。

我的电脑是 Arm 的，能用吗？

能。下载 arm64 便携版就是原生版本，不用模拟跑。安装包目前只出给常见 64 位电脑，Arm 设备请用便携版。

遇到问题去哪说？

到 GitHub 仓库提 Issue，附上版本号和 %LOCALAPPDATA%\MailDog\ 里的日志片段，能省很多来回。
