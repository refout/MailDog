为日常收信做好每个细节

从实时收信到本地索引，从 HTML 净化到托盘常驻，MailDog 把“读邮件”这条路走顺。

✉

统一邮箱视图

顶部聚合所有账户的收件箱、已发送、草稿等默认文件夹，下面按账户展开二级文件夹，未读数一目了然。

⚡

IMAP IDLE 实时收信

每个账户维持独立 IDLE 连接，新邮件即时同步；断线按指数退避重连，睡眠唤醒后自动恢复。

🗄

本地 SQLite 索引

账户、文件夹、邮件头与正文缓存到本地，离线也能翻看已同步内容，搜索与跳转更快。

🛡

HTML 白名单净化

保留安全的内联样式与 <style>，默认拦截远程图片，渲染失败自动降级为纯文本。

🔔

通知与托盘常驻

气泡通知带发件人头像与自定义提示音，点击直达对应邮件；关闭 UI 后 Engine 继续在托盘工作。

📦

全 Native AOT 单文件

两个自包含 exe，无需安装 .NET 运行时；原生库嵌入，首次启动解压到本地缓存。
