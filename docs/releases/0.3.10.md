# MailDog 0.3.10 发布说明

日期：2026-11-27

状态：待发布。GitHub Actions 将构建 Windows/Linux 五个资产，并发布到 https://github.com/refout/MailDog/releases/tag/v0.3.10。

## 这一版做了什么

0.3.10 继续收口界面：标题栏交回系统，滚动条回到自动隐藏，阅读区附件压成单行，CLI 调用记录从独立窗口搬进设置页并改成可读摘要。

### 标题栏

- 删除自绘标题栏和 `WindowDrawnDecorations` 样式，Windows 恢复系统原生标题栏；保留 Mica/Blur 透明提示和透明窗口背景。
- `MainWindow.axaml.cs` 在 Windows 11 22621+ 按当前材质设置 `DWMWA_SYSTEMBACKDROP_TYPE`：mica=2、acrylic=3、none=1；材质生效时把标题栏颜色和边框颜色复位为系统默认。
- 不支持 DWM 材质的系统继续使用系统标题栏，不再自绘 caption 按钮。

### 滚动条

- 左栏文件夹树、中栏邮件列表改回 Fluent 默认 `AllowAutoHide=True`，纵向滚动条改为 `Auto`；删除运行时强制常显逻辑。
- 保留 10px 轨道和 4px 圆角滑块；三栏不再常驻滚动条，也不再用滚动条占位压内容。

### 附件

- 阅读区附件从 200–230px 卡片改成单行列表：复选框、回形针、文件名、大小、打开、下载、拖出一个横向 Grid。
- 文件名 `NoWrap` + `CharacterEllipsis`；附件区 `MaxHeight` 从 176 降到 132，超出时在附件区内部滚动。
- 邮件列表增加 `HorizontalScrollBarVisibility="Disabled"`，消除列表底部意外出现的横向滚动条。

### CLI 调用记录

- 删除独立 `CliCallsWindow`；记录与 Agent 权限改为「设置 → 工具 → 查看调用记录与 Agent 权限」内嵌展开，不再弹窗。
- 默认显示可读摘要：主题、发件人、收件人/抄送、时间、附件、正文预览；收件地址数组按地址列表合并，不再出现 `["..."]`。
- 列表不再显示 JSON 字样；原始输出收进详情底部「原始记录（调试用）」默认折叠区。
- 新增 `CliCallDetailFormatter`，支持对象、NDJSON 列表和数组，并补 3 项格式化测试。
