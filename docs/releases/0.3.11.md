# MailDog 0.3.11 发布说明

日期：2026-11-27

## 这一版做了什么

0.3.11 只收主窗口界面：搜索范围改成下拉，附件拖出不再依赖按钮，左侧两栏继续收紧留白，账户树与邮件列表头像左移，同步状态不再占用底部状态栏。

### 搜索与附件

- 搜索范围从“点一下切换”的按钮改成 `ComboBox`，明确列出「当前文件夹 / 全部邮箱」，不再需要从按钮文案猜当前状态。
- 删除附件行和附件工具栏里的「拖出 / 拖出所选」按钮，保留「打开 / 下载」；整行现在就是拖拽源。
- 选中多个附件后，拖任意一条已选行会一起拖出；没有多选时只拖当前行。附件行内部点到按钮或复选框不会误触发拖拽。

### 左栏与中栏留白

- 三栏外框左右边距 `12 → 8`，左栏内容左右 `16 → 12`，中栏标题、搜索与批量栏左右 `16 → 12`；上下边距、栏间距和阅读区未动。
- 账户树 `TreeView Padding 11 → 4`、`TreeViewItem Padding 4 → 2`，并给树整体加 `-8` 左偏移；账户头像较 0.3.10 左移约 17px，文件夹层级缩进保留。
- 邮件行左边距 `10 → 2`，邮件列表项边距 `6 → 4`；列表头像较 0.3.10 左移约 10px。

### 同步状态

- 同步中、同步失败、文件夹/邮件加载和手动“立即同步”不再写入底部 `StatusMessage`，底栏不会随着每次同步出现又消失，也不会再把三栏整体顶高。
- 同步状态仍显示在左栏账户行内；同步失败继续由账户行和顶部离线横幅承载。
- 底栏保留给明确的操作结果（保存附件、移动邮件等）和启动连接提示。
