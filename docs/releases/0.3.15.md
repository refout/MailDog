## 这一版做了什么

0.3.15 把主工作区从三张独立圆角卡片改成一张连续页面，同时收掉底部状态条，把加载提示改成不占布局的顶部细进度条。Outlook/Hotmail 在服务端禁用 IMAP/SMTP 时不再被当成普通认证失败反复重试。

### 界面

- 移除三张 `workspace-column` 卡片的外轮廓和卡片间隙；`MailColumns` 直接放在内容区 `Grid.Row=1`，不再套 `MailWorkspaceFrame` 外层卡片，也不再设置 `ColumnSpacing`。
- 三列改为透明背景、0 边框、0 圆角；左栏右侧保留 1px `StrokeDefault` 分割线，列表右侧保留 1px `StrokeSubtle` 分割线，阅读区无边框。
- 根布局从 `Auto,*,Auto` 改为 `Auto,*`，删除底部状态条及其绑定属性；主工作区不再因同步状态出现/消失而上下跳动。
- 标题栏下方新增 2px `ProgressBar`，`Grid.RowSpan=2`、`ZIndex=90`、`VerticalAlignment=Top`、`IsHitTestVisible=False`，只在 `IsBusy` 时显示，不占布局高度。
- 三栏内部的 8px 仍作为列内容 padding 保留；页面外不再有第二层外边距。

### 修复

- Outlook/Hotmail 的 IMAP 返回 `User is authenticated but not connected.`、SMTP 返回 `SmtpClientAuthentication is disabled for the Mailbox.` 时，识别为服务端协议受限，不再当成普通登录失败。
- 新增 `AccountStatus.ProtocolBlocked`，设置页、账户健康面板和诊断包显示「邮箱协议受限」。
- 自动同步跳过 `AuthRequired`/`ProtocolBlocked` 账户，手动「立即同步」仍带 `force: true` 重试；同一账户的同步请求按账户去重，空文件夹不再每 0.7 秒重复刷新。
- 新增 `AuthenticationTraceLogger`，只保留服务端 `NO/BAD` 响应，不记录客户端认证载荷；认证异常会带上服务端原文，便于区分密码错误与协议封禁。

## 已知限制

- 受信任 OV/EV 代码签名证书尚未提供；未配置 secrets 时 CI 的 Windows 产物仍为未签名。
- Outlook.com 默认可能关闭 POP/IMAP；新注册个人 Outlook 邮箱还可能被微软按反垃圾策略禁用 SMTP AUTH。MailDog 只能识别并显示协议受限，无法在客户端绕过服务端限制。
- `PrintWindow` 验收截图会包含 Windows 的不可见缩放边框；实际客户区从 `GetClientRect` 的 `(0,0)` 开始，页面本身已铺满。
