# MailDog 0.3.7 发布说明

日期：2026-11-26

状态：发布中（v0.3.7，2026-11-26）。

## 这一版做了什么

0.3.7 不改造型，只收 0.3.6 实机使用后暴露出来的界面细节。邮件收发、CLI 与发布工程不变。

### 主窗口

- 三栏间距从 12px 收到 8px，卡片宽度与折叠逻辑不变。
- 左栏文件夹树向右让出滚动条空间，列表区也留出右侧余量；滚动条不再压在文字和徽标上。
- 左栏底部设置入口从 40px 高收到 28px，底边距同步收紧，不再占掉一整条 footer。

### 滚动条

- 所有 Avalonia 滚动条统一为 10px 轨道、圆角 4px 滑块，悬停时滑块保持圆角，不再是直角。
- 关闭自动隐藏后，滚动条会占用布局宽度，正文和列表不会被覆盖。
- 邮件 HTML 阅读区给 WebView2 注入 `::-webkit-scrollbar` 样式，宽度 10px、滑块圆角 5px，浅色和深色各一套；右侧阅读区和左栏、列表的滚动条观感统一。

### 设置页

- 左侧设置导航顶部只保留 `MailDog`，删除产品定位副标题。
- 关于页删除产品定位介绍，只保留版本、平台、第三方许可这些实际信息。
- 设置页左侧 footer 的内边距同步收紧。

### Windows 标题栏

- 最小化、最大化、关闭按钮统一为方形命中区，不再继承通用按钮的 6px 圆角。
- 关闭按钮悬停恢复系统红 `CaptionButtonCloseBackground`，按下使用 `CaptionButtonCloseBorderBrush`，和原生标题栏一致。
- 品牌区和透明标题条逻辑保持 0.3.6 行为。

## 验证结果

```powershell
dotnet build src\MailDog.slnx -c Release -p:OS=Windows_NT -p:EnableWindowsTargeting=true --nologo
dotnet test src\MailDog.slnx -c Release --no-build --nologo
```

- 构建 0 警告 0 错误。
- 187 项测试通过：Html 31、Contracts 23、Cli 27、UI 38、Mail 68。
- Windows 11 实机截图确认三栏间距、左栏滚动条占位、底部设置入口高度和 WebView 阅读区滚动条样式。
- 关闭按钮悬停红、方角命中区只做了代码路径检查；鼠标悬停状态没有纳入自动化截图。

## 已知限制

- 受信任 OV/EV 代码签名证书尚未提供；未配置 secrets 时 Windows 产物仍为未签名。
- 正式崩溃上报端点尚未提供；默认关闭，不会联网。
- 本机没有 MSVC/C++ Build Tools，Windows Native AOT 产物由 GitHub Actions `windows-latest` 构建。
- Linux 真实桌面托盘、通知点击与 WebKitGTK 仍未验收；WSLg 只覆盖 X11 窗口启动。
- 标题栏按钮的点击、拖动与双击最大化仍只完成视觉检查和代码路径检查，没有实机自动化验收。
