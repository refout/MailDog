# MailDog 0.3.14 发布说明

日期：2026-11-28

状态：发布准备中。等待 GitHub Actions 完成 Windows/Linux 五个平台构建并上传 Release 资产。

## 这一版做了什么

0.3.14 完成六组大文件的职责拆分，同时收口主工作区与设置页的铺满方式。拆分只移动成员，类名、公开成员、事件处理器、IPC 路由和 XAML 绑定路径保持原样；界面上去掉设置页与主工作区的第二层外边距，页面直接铺满内容区。

### 重构

- `MainWindowViewModel` 7,832 行拆成 9 个 `partial class`，最大文件 1,471 行。
- `SqliteStore` 3,118 行拆成 5 个 `partial class`，最大文件 795 行。
- `ImapSyncService` 1,660 行拆成 4 个 `partial class`，最大文件 515 行。
- `ComposeViewModel` 1,645 行拆成 6 个 `partial class`，最大文件 449 行。
- `MainWindow.axaml.cs` 1,526 行拆成 6 个 `partial class`，最大文件 421 行。
- `EngineHost` 1,366 行拆成 5 个 `partial class`，最大文件 346 行。

### 界面

- 设置页不再套外层圆角卡片，也不再加 4px 二级外边距；`SettingsView` 直接铺满内容区，根 `Border` 用 8px 圆角统一裁剪。
- 设置页内部保留左栏、标题栏和内容区的分区线；分区线仍是直角，页面只有最外轮廓和内部卡片带圆角。
- 主工作区移除 `MailColumns` 的 4px 外层 `Margin`，三栏直接铺满内容区；栏与栏之间的 4px `ColumnSpacing` 保留，三栏各自的 8px 圆角形成外轮廓。

### 修复

- Outlook 登录完成时 `AccountChanged` 与 `AuthStateChanged` 连续触发，账户列表重载改为单飞串行并带版本号，避免 `RefreshFolderTreeAsync` 枚举账户时集合被 `Clear` 打断。
- 设置页账户卡片不再显示瞬态同步状态，避免周期同步把卡片撑高再回落；同步状态仍留在左侧账户树。
