日期：2026-11-27

## 这一版做了什么

0.3.13 只收三栏之间的间距：`ColumnSpacing` 从 8px 改为 4px，与主窗口四边的 4px 留白同档。左右栏宽度保持 240 / 360 不变，省出的 4px 全部给右侧阅读区；四边留白、圆角和控件尺寸均未改动。

### 间距

- 三栏工作区 `ColumnDefinitions="240,360,*"` 保持不变，栏间空隙 `8 → 4`，两处缝隙同时收窄。
- 主窗口外层 `Margin="4"` 与栏间 `4px` 对齐，三块卡片之间的视觉密度统一。
- 头像、文件夹树、邮件列表和阅读区的内容布局不受影响，阅读区宽度增加 4px。
