# MailDog 0.3.8 发布说明

日期：2026-11-26

状态：本机打包并覆盖安装（v0.3.8，2026-11-26）；GitHub 远程推送待恢复。

## 这一版做了什么

0.3.8 继续收 0.3.7 实机反馈里的两处布局问题，不改邮件收发、CLI 与发布工程。

### 左栏滚动条

- 文件夹树去掉右侧的额外内缩，滚动条贴到左栏卡片右边框内侧。
- 树项右侧保留 6px，文件夹名和未读徽标仍与滚动条有间距。
- 顶部按钮、账户标题和底部设置入口保持原来的 16px 右边距，和树项内容对齐。

### 图片附件

- 附件图片预览从最大 200px 收到 112px 高，附件卡宽度收到 200–230px。
- 图片附件改成固定 112px 高的缩略区，两张卡可以并排，不再一张占满一行。
- 附件区最高 224px，附件多时在附件区内滚动，正文不会被附件挤出可视区。

## 验证结果

```powershell
dotnet build src\MailDog.slnx -c Release -p:OS=Windows_NT -p:EnableWindowsTargeting=true --nologo
dotnet test src\MailDog.slnx -c Release --no-build --nologo
```

- 构建 0 警告 0 错误。
- 187 项测试通过：Html 31、Contracts 23、Cli 27、UI 38、Mail 68。
- 本机 self-contained 安装包覆盖安装，安装后 `MailDog.UI.exe` 文件版本 `0.3.8.0`，窗口正常启动。

## 已知限制

- 受信任 OV/EV 代码签名证书尚未提供；未配置 secrets 时 Windows 产物仍为未签名。
- 本机没有 MSVC/C++ Build Tools，本机包为 self-contained 单文件，不是 CI 的 Native AOT 产物，体积更大。
- GitHub 仍被本机 hosts 指向 `127.0.0.1`，远程 `main`、`v0.3.8` tag 与 Release 尚未更新。
- 关闭按钮 hover 红色仍在系统 caption 层，自动化截图抓不到悬停态。
