# MailDog 0.3.5 发布说明

日期：2026-11-26

状态：发版准备完成，待配置签名证书与上报端点后打 tag。

## 这一版做了什么

0.3.5 是发布工程版本，邮件功能与 0.3.4 保持一致，主要把 Windows 分发链路补齐。

### 代码签名

- 新增 `src/build/sign.ps1`：支持 PFX 文件，也支持从 `MAILDOG_SIGN_PFX_BASE64` 读取；密码从 `MAILDOG_SIGN_PFX_PASSWORD` 读取。
- 可签单个 exe 或目录；目录自动签 `MailDog.Engine.exe`、`MailDog.UI.exe`、`MailDog.Cli.exe`。
- 优先使用 `signtool.exe`，找不到时回退 PowerShell `Set-AuthenticodeSignature`。
- 默认 RFC 3161 时间戳 `https://timestamp.digicert.com`，可由 `MAILDOG_SIGN_TIMESTAMP_URL` 覆盖。
- `package.ps1` 在 Windows、且存在 `MAILDOG_SIGN_PFX_BASE64` 时，于压缩打包和生成安装包之前签名。
- `.github/workflows/release.yml` 已接入 `MAILDOG_SIGN_PFX_BASE64`、`MAILDOG_SIGN_PFX_PASSWORD` 与 `MAILDOG_SIGN_TIMESTAMP_URL`。
- 没有配置 PFX 时跳过签名，产物仍可构建和发布；配置了 PFX 但签名失败会终止。

### 崩溃上报

- UI 未处理异常仍写本地 `crash.log`，不改变原有排查方式。
- 配置 `MAILDOG_CRASH_ENDPOINT` 或 `%LOCALAPPDATA%\MailDog\crash-endpoint.txt` 后，额外异步 POST 一份崩溃摘要。
- 只接受 `https`，或本机 `http://localhost` / `127.0.0.1` / `[::1]`。
- 发送失败写入 `crash-pending/`，下次启动按时间顺序重试，成功一个删一个。
- 上报字段只有 `app/version/time/kind/exception/stack`，**不含异常消息**，避免带出邮件地址、主题或正文。
- 默认不联网；没有端点时行为与之前一致。

### 验收补齐

- Windows 安装包在 XIZXI 干净用户上实测 0.3.4 安装、卸载、0.3.3 安装、0.3.4 覆盖升级、最终卸载全部通过；安装目录与邮件客户端注册项清理正确，用户数据库保留。
- Outlook 真实邮件上通过 UI 点击「标记垃圾邮件并拦截发件人」：邮件移入 Junk，规则落库；同发件人新邮件到达后自动进入 Junk。
- `List-Unsubscribe` 的 https / mailto / One-Click 解析由单元测试覆盖；未向第三方提交退订请求。

## 验证结果

```powershell
dotnet build src\MailDog.slnx -c Release -p:OS=Windows_NT -p:EnableWindowsTargeting=true --nologo
dotnet test src\MailDog.slnx -c Release --no-build --nologo
```

- 构建 0 警告 0 错误。
- 182 项测试通过：Html 31、Contracts 18、Cli 27、UI 38、Mail 68。
- 自签 PFX 签名 `MailDog.Engine.exe`、`MailDog.UI.exe`、`MailDog.Cli.exe` 成功；`Get-AuthenticodeSignature` 的 `UnknownError` 是自签根不受信任的预期结果，`SignerCertificate` 正确。
- 用自签 PFX 走完整 `package.ps1 -Version 0.3.0 -Runtime win-x64 -SkipPublish -Installer`，zip 与 setup 均生成，退出码 0。

## 已知限制

- 受信任 OV/EV 代码签名证书尚未提供；未配置 secrets 时 0.3.5 产物为未签名。
- 正式崩溃上报端点尚未提供；默认关闭，不会联网。
- 本机没有 MSVC/C++ Build Tools，0.3.5 的 Native AOT 产物需由 GitHub Actions `windows-latest` 或具备 Build Tools 的机器构建。
- Gmail、自定义 IMAP/SMTP 真实账户与 Linux 桌面托盘/WebKitGTK 仍未验收。
