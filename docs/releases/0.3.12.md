# MailDog 0.3.12 发布说明

日期：2026-11-27

状态：已发布（2026-11-27）。GitHub Actions 全平台构建通过，Release 已上传 Windows/Linux 五个资产：https://github.com/refout/MailDog/releases/tag/v0.3.12

## 这一版做了什么

0.3.12 只收主窗口的留白和圆角：四边原有外层与栏内的双重边距压成统一的 12px，三栏卡片、按钮、输入框、设置页和写信页的圆角整体降一档。

### 四边留白

- 三栏外框从 `8,10,8,12` 收成统一 `4`；左栏内容从 `12,16` 收到 `8`，中栏标题、搜索和批量栏从 `12,16` 收到 `8`，阅读区从 `16` 收到 `8`。
- 中栏底部、阅读区底部和左栏设置入口原本叠加的外边距与栏内边距一起收掉；四边总留白从原来的 20–28px 统一到 12px。
- 三栏之间的 `ColumnSpacing` 保持 8px，不改栏宽和阅读区宽度。

### 圆角

- 三栏工作区 `12 → 8`；卡片与弹层 `8 → 6`；按钮、输入框、附件行和状态块 `6 → 4`；面板 token `10 → 6`。
- 设置页分组卡片、规则卡片、账户卡片、写信页字段与附件卡、CLI 调用面板同步使用新圆角。
- 头像、状态圆点、未读胶囊和颜色胶囊保持原有圆形/胶囊形态，不跟着压扁。
