# MailDog 0.3.9 发布说明

日期：2026-11-26

状态：已发布（2026-11-26）。GitHub Actions 全平台构建通过，Release 已上传 Windows/Linux 五个资产：https://github.com/refout/MailDog/releases/tag/v0.3.9

## 这一版做了什么

0.3.9 收口 0.3.8 实机反馈里的七处界面问题，不改邮件收发、CLI 与发布工程。

### 窗口与设置

- 标题栏右侧留出 150px 给系统 caption 按钮，关闭按钮重新可点。
- 关于页外层去掉 880px 宽度上限并改为拉伸，卡片铺满内容区，与其他设置页一致。

### 三处滚动条

- 左栏文件夹树、中栏邮件列表强制 10px 纵向滚动条常显，不再依赖鼠标悬停。
- 模板内的 ScrollViewer 单独设置 `AllowAutoHide=false`，避免窗口级样式被模板默认值覆盖。
- HTML 正文的 WebView 滚动条固定 10px，透明 2px 内边距加 4px 圆角，滑块宽度与 Avalonia 三栏一致。

### 正文与附件

- 附件卡去掉 112px 高的大图预览，只保留文件名、大小和打开/下载/拖出，附件区上限收到 176px。
- 选中邮件后不再为未显示的附件预览下载和解码图片字节。
- HTML 渲染失败增加 2 次自动重试（400ms、800ms）和 12 秒导航看门狗；仍失败才切纯文本，并在正文提示重试次数。

### 左栏边距

- 账户树的 10px 滚动条始终占位，内容右侧与顶部按钮、底部设置入口统一到 16px 级别。
- 树项去掉额外 6px 右缩进，选中态和文件夹行不再出现明显左右不等。
