# 阶段 21 验收：规则增强（2026-11-25）

## 范围

- 自动移动到文件夹：`RuleDto.TargetFolderId`；命中后优先移到目标文件夹，目标为空时回退 `MoveToJunk`；目标文件夹必须与邮件同账户，否则跳过并记日志。
- 规则试运行与命中预览：设置页每条规则新增“预览”，Engine 扫描最多 200 封历史邮件，返回命中数、目标文件夹与前 5 封样例，不改邮件。
- 历史邮件回溯应用：设置页每条规则新增“回溯”，Engine 立即返回接受数量，再在后台批量标已读 / 加旗标、逐封移动并广播 `MailChangedEvent`；单次最多 200 封。
- 数据库迁移：schema 版本 15，`rules` 表新增 `target_folder_id`。

## 未覆盖与风险

- UI 已通过 Avalonia 编译；HOME 会话不能显示窗口，未逐项点击“预览”“回溯”以及新规则的目标文件夹下拉。
- 回溯在后台执行，不提供中途取消；单次上限 200 封，避免一次占用 IMAP 连接太久。重复点击会重复处理已匹配邮件。
- 目标文件夹下拉只列当前规则账号下可写文件夹，因此选择“全部账号”时不能指定移动目标。全局规则仍可使用垃圾邮件移动。
