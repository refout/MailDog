- 自签证书测试不能证明真实证书链校验正确。
- JumpList 测试写入一条指向 `messageId=900001` 的测试快捷方式，未清理；真实用户环境重跑会替换旧测试链接。

- 垃圾规则 UI 测试使用 UI Automation 点击，未做人工鼠标点击；菜单命令、引擎落库与 IMAP 移动均已独立核对。
