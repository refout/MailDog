## 手工验收清单

1. 准备一个含 2 封邮件的 `.mbox` 和一个 `.eml`，在设置页点击“导入 mbox / eml”。
2. 确认提示“已导入 N 封”，目标显示为当前账户的收件箱。
3. 等待同步，确认新邮件出现在收件箱且正文/附件完整。
4. 点击“导出当前账户 mbox”，保存后重新导入 Thunderbird，确认邮件数量和正文正确。
5. 导入一个正文包含行首 `From ` 的邮件，导出后再次导入，确认没有被拆成两封。
6. 对只读账号或拒绝 APPEND 的服务器导入，确认提示跳过数量与错误样例。

## 已知限制

- 导入依赖 IMAP `APPEND`；不做去重，重复导入会产生重复邮件。
- 导出遍历全部本地索引；只导出已同步邮件，不含未下载的服务器邮件。
- 导出不含账户配置、标签、规则、联系人；完整状态迁移应使用备份功能。
- UI 只通过 Avalonia 编译验证，当前会话未在可交互桌面点击验收。
