## 命令行冒烟

隔离 `LOCALAPPDATA` 后运行：

- `maildog schema --json`：包含 `pending`、`approve`、`deny`、`--read-only`、`--queue` 和 `readOnly` 字段。
- `maildog pending --json`：空队列退出 0。
- `maildog deny nosuch`：退出 2，提示待确认项不存在。
- `maildog send --to a@example.com --subject x --read-only`：退出 4，提示写命令被拒绝；没有连接 Engine。
- `CliQueueTests` 已经覆盖正常权限下的草稿/发送入队与审批，不再依赖真实账户。
