# 阶段 19 验收：收件箱治理（2026-11-25）

## 范围

- 一键退订：从邮件 `List-Unsubscribe` / `List-Unsubscribe-Post` 头解析退订地址；RFC 8058 一键退订直接向 URL POST `List-Unsubscribe=One-Click`，否则交给系统打开网页或 `mailto:`。
- 标记垃圾邮件并拦截发件人：把当前邮件移到账户的垃圾邮件文件夹，同时保存一条 `from` 规则（`MoveToJunk + Mute`），之后的新邮件直接进垃圾箱且不弹通知。
- 规则增强：`RuleDto.MoveToJunk`；规则设置页新增“移入垃圾邮件”动作；新邮件命中后由 Engine 异步调用 IMAP 移动。
- 数据库迁移：schema 版本 14，`rules` 表新增 `move_to_junk`。

## 未覆盖与风险

- UI 已通过 Avalonia 编译；HOME 会话不能显示窗口，未逐项点击“退订这封邮件”和“标记垃圾邮件并拦截发件人”。
